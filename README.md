# A Life Between Lines — Portfolio starter

A dark-academia, interactive book portfolio built with React, Vite, Tailwind CSS and `react-pageflip`.

## Requirements

- Node.js 20.19+ (or a compatible current LTS release)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## First customisations

1. Replace `hello@example.com` in `src/App.jsx` with your actual public contact email.
2. Verify and update the leadership timeline and project descriptions.
3. Replace the placeholder poem with a piece you want to publish.
4. Add project screenshots to `public/images/` and place them inside the relevant project page.
5. Update LinkedIn to your actual profile URL.
6. Add a custom favicon and social preview image in `index.html` / `public/`.

## Notes

- This is a front-end starter; no backend is required for the portfolio itself.
- The book uses a fixed page design with responsive sizing and touch support.
- The page count and page indicator should be adjusted if you add or remove book pages.
- Keep the content concise: realistic book pages have limited space. Consider opening detailed project case studies in a dedicated page or modal rather than overcrowding the spreads.
